# IBM Plex no build web

Arquivos WOFF2 completos de IBM Plex Sans e IBM Plex Mono, nas mesmas famílias e pesos usados pela aplicação. Origem: [IBM/plex](https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25/packages), revisão `763c36ef9117782905ae010056dfbe8fd2653a25`. Cada WOFF2 foi comparado ao Git blob da revisão. A licença OFL 1.1 está em `LICENSE.txt`, com um espaço final removido para o gate de whitespace.

Os arquivos locais evitam que o build consulte o Google Fonts e receba CSS inválido ou indisponível. Se os arquivos forem atualizados, conferir novamente origem, licença e integridade antes de mudar a revisão.
