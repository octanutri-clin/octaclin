# G01 OctaClin REV11 — como usar

1. Leia `PARECER_VALIDACAO_G01_REV11.md`.
2. Execute `python -m unittest -v test_g01_rev11.py` na pasta extraída.
3. Execute `python gerar_evidencias_rev11.py` para regenerar CSVs, resumo e log.
4. Confira `resultado_resumo_G01_REV11.json`: o G01 global **NÃO** está aprovado.
5. Entregue `MENSAGEM_CODEX_G01_REV11.md` ao Codex, apontando para esta pasta no repositório.
